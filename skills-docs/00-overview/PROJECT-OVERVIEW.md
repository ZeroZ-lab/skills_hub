## 1. 背景与动机

AI 编程助手（Agent）正在成为开发者工作流的核心工具。这些 Agent 通过加载 **Skills**（可复用指令集）和连接 **MCP Servers**（工具服务）来获得专业领域的能力扩展。

当前生态中已有一些管理方案，但各有局限：

| 方案 | 优势 | 局限 |
|------|------|------|
| **Vercel Skills CLI** (`npx skills`) | 42+ Agent 支持、Provider 扩展、双 Lock 文件 | 需 Node.js 运行时、纯 CLI 交互、不管理 MCP |
| **cc-switch** | GUI 可视化、MCP 统一管理、深度链接 | 仅支持 5 个 Agent、硬编码扩展、无 Provider 机制 |
| **手动管理** | 无依赖 | 易出错、无法跟踪版本、跨 Agent 重复劳动 |

**Skills Manager** 旨在融合两者优势，提供 **Skills + MCP 统一管理** 的原生图形化工具。

---

## 2. 产品定位

**Skills Manager** 是一款面向个人开发者和团队的跨平台桌面应用：

- **统一管理**: Skills 安装/更新/发现 + MCP Server 配置/同步，一站式管理
- **可视化**: 以图形界面替代命令行，降低使用门槛
- **广泛兼容**: 支持 42+ AI Agent（借鉴 Vercel Skills 的完整注册表）
- **可扩展**: Provider 模式支持 GitHub、GitLab、Well-Known 协议、私有 Registry 等来源
- **团队协作**: 双 Lock 文件设计（全局 + 项目级），项目级 Lock 可提交到 VCS
- **本地优先**: 所有数据本地存储，不依赖云端服务
- **零依赖**: 无需 Node.js，单文件原生可执行程序

## 4. 目标用户

| 用户类型 | 特征 | 核心诉求 |
|---------|------|---------|
| 新手用户 | 首次接触 AI Agent Skills | 可视化浏览、一键安装、无需记命令 |
| 个人开发者 | 使用 1-2 个 AI Agent | 方便管理 Skills 和 MCP Server |
| 小型团队 | 2-5 人，使用不同 Agent | 统一配置、Lock 文件共享、批量操作 |
| AI 工具重度用户 | 使用多种 AI Agent | 跨 Agent 统一管理、MCP 格式自动转换 |
| Skill 开发者 | 自己编写 Skills | 本地 Symlink、实时更新、深度链接导入 |
